# Art direction

Eight sheets, settled 24 August 2026. The visual reference for the whole
build. If something is not on a sheet, draw it in the same language.

**The sheets:** <https://claude.ai/code/artifact/733c6456-904e-475f-a473-bdd32d77b0b0>

1. The cast: Sid, Bruno and the hero, full body
2. Faces: ten expression heads, five each
3. The house outside
4. The house you search: 13 rooms, 26 search spots
5. The same house, rigged: 24 anchor points, numbered and keyed
6. The workbench in Hendrix's room
7. The junk: 16 common items and 4 rare ones
8. Traps going off, and the five beats every payoff hits

## Drawing rules

- **Ink.** Every solid gets a black outline. Outer 5px, interior 3.2px,
  fine detail 2px. Round joins and caps.
- **Shading is one tone.** Shadow is black at 18% over the base colour,
  highlight is white at 12%.
- **No colour is written into a drawing.** Everything resolves to a token
  in `css/tokens.css`.
- **Faces do the work.** Eyebrows, pupils and mouth carry the joke. Stars
  for dazed, spirals for very dazed, sweat for panic, `#@!%` for swearing.
- **Nobody is hurt.** They are humiliated.
- **Every trap payoff hits five beats:** approach, trigger, chaos,
  reaction, recover.

Open decision: the sheets use Luckiest Guy for headings; the game uses the
system font.
