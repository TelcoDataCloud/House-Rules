# Sounds

Free sounds, all Creative Commons Zero (CC0), which means anyone may use
them for anything:

- **Kenney** (www.kenney.nl): *Impact Sounds*, *Interface Sounds*,
  *Foley Sounds*, *RPG Audio*, *Retro Sounds 2*, *Music Jingles* and
  *Music Loops* (Farm Frolics by day, Mishief Stroll at night with
  Drumming Sticks on top, Alpha Dance for the disco ball).

The farts, burps, sneezes, snores and zombie laughs are not files: they
are made by `js/voice.js` while you play.

The sounds are packed into text files (`sfx-1.json`... and `music-1.json`...,
listed in `packs.json`) because GitHub uploads here only take text.

## Your own sounds

Record a sound on a phone, name it after the sound it replaces, with a
number: `groan-1.mp3`, `cheer-1.mp3`. Send it to Claude in the chat and it
gets packed in. A sound with several versions (`bonk-1`, `bonk-2`) plays
one at random. The names the game uses:

spoon, pan, chicken, mallet (the weapons), bonk, boing, splat, pop,
twang, whoosh, dong, thud, pin (skittles), build, mine, chop, tap, clang,
click, nope, coin, slip, upgrade, drip, cloth, door, super, cheer,
joined (someone cured), dawn, night, sad, win.
Made from scratch, but a recording with the name replaces them:
groan, laugh, sneeze, burp, fart, snore.
